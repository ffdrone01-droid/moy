Kesalahan yang Sering Terjadi

Hindari tiga kekeliruan sintaks umum berikut saat menulis kode HTML.

01 Link tanpa href link_off
Salah:
<a>Google</a>
Benar:
<a href="https://google.com">Google</a>

Tanpa atribut href, tag <a> tidak memiliki alamat tujuan sehingga tidak dapat berfungsi sebagai tautan interaktif.

02 Image tanpa alt hide_image
Salah:
<img src="photo.jpg">
Lebih baik:
<img src="photo.jpg" alt="Foto pemandangan">

Atribut alt wajib ditambahkan untuk aksesibilitas pembaca layar (screen reader) dan fallback saat berkas gambar gagal diunduh.

03 Path gambar salah broken_image
Alamat file pada atribut src harus tepat sesuai nama dan struktur folder gambar (memperhatikan ejaan dan huruf kapital).

Jika berkas berada di folder terpisah, pastikan jalur path relatif tepat (misal: images/photo.jpg).
